INSTALLATION AVEC GITHUB PAGES

1. Creez un depot GitHub public (ex. mes-blagues).
2. Ajoutez a la racine du depot les 5 fichiers : index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.
3. Dans Settings > Pages, choisissez Deploy from a branch, branche main, dossier /(root), puis Save.
4. Attendez la publication et ouvrez https://VOTRE-IDENTIFIANT.github.io/mes-blagues/ dans Brave sur votre Redmi.
5. Menu Brave > Installer l’application ou Ajouter à l’écran d’accueil.
6. Ouvrez une premiere fois l’application avec Internet pour activer le mode hors ligne.

Attention : avec un depot public, les blagues sont accessibles a toute personne connaissant le lien.
